1. File Purpose & Role

This module contains the formal PyTorch class definitions for the proposed Multimodal Cross-Attention Network (MultimodalPricingNet) as well as the 3 standalone baseline architectures (TabularOnlyBaseline, TextTabularBaseline, VisionTabularBaseline) used for empirical benchmarking.

Explanation: Heterogeneous modalities have different dimensionalities (Vision: 512, Text: 384, Tabular: 8). These projection sub-networks project all modalities into an identical 128-dimensional latent space so they can participate in multi-head cross-attention as equal-sized tokens.

# Multi-Head Attention layer
self.modality_attention = nn.MultiheadAttention(
    embed_dim=embed_dim,
    num_heads=num_heads, # 4 heads
    dropout=dropout_p,
    batch_first=True,
)
self.fusion_norm = nn.LayerNorm(embed_dim)

Explanation: Uses 4 attention heads (each with 32 dimensions = 128 total). Multi-head attention allows the model to jointly attend to information from different representation subspaces at different positions. LayerNorm stabilizes hidden state dynamics across batches.

# Dual Prediction Heads
self.demand_head = nn.Sequential(
    nn.Linear(128, 64),
    nn.ReLU(),
    nn.Linear(64, 1),
)
self.elasticity_head = nn.Sequential(
    nn.Linear(128, 64),
    nn.ReLU(),
    nn.Linear(64, 1),
)

Explanation: Multitask head design: The demand head predicts non-negative customer order volume, while the elasticity head outputs a negative elasticity factor (via -softplus) to ensure downward-sloping demand curves in accordance with economic theory.

4. Important Viva Terms to Highlight

BatchNorm1d vs LayerNorm BatchNorm normalizes across the batch for each feature (good for convolutional/MLP projections), while LayerNorm normalizes across the feature dimension for each sample independently (ideal for attention sequences).
Softplus Activation A smooth continuous approximation to ReLU: f(x) = ln(1 + e^x). Negating softplus ensures that price elasticity is strictly negative (≤ 0), guaranteeing economically valid behavior.

5. Likely Viva Questions & Answers

Q: Why did you use 4 attention heads instead of 1?
A: Multiple heads allow the network to simultaneously focus on different inter-modal aspects—e.g. one head evaluates how text specs match competitor price, while another evaluates whether photo quality justifies an MSRP premium.
