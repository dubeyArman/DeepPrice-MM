Feature Extraction, Cross-Attention Training, and Comparative Ablation Benchmarks

PyTorch Sentence-BERT ResNet-18 Ablation Study

1. File Purpose & Role

This is the core machine learning engine. It extracts pre-trained visual and textual embeddings, standardizes tabular economic metrics, trains the proposed cross-attention multimodal network, trains 3 ablation baseline models for academic comparison, and evaluates revenue lift.

4. Important Viva Terms to Highlight

Transfer Learning Using pre-trained weights from huge models (ResNet-18 on ImageNet, S-BERT on billions of sentences) rather than training from scratch with limited data.
Residual Connection (Skip Connection) Adding the original input back to the attention output (modalities + attn_out) to prevent gradient vanishing and preserve original modality signals.

5. Likely Viva Questions & Answers

Q: Why did you use AdamW optimizer instead of plain SGD?
A: AdamW provides adaptive learning rates per parameter with decoupled weight decay (L2 regularization), converging much faster and avoiding overfitting on deep neural network architectures.
