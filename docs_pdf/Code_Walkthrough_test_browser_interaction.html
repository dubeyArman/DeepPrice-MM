Code Walkthrough: test_browser_interaction.py

Automated End-to-End Integration Testing & Headless Browser Verification

Playwright End-to-End Testing UI Automation

1. File Purpose & Role

This script provides automated quality assurance and verification. Using Microsoft Playwright, it spins up a headless Chromium browser instance, clicks through preset products, navigates dataset filters, clicks "Test Price" buttons across multiple categories, and validates that the dynamic pricing engine outputs correct results without crashing.

2. Libraries Used and Technical Justification

Library Imported Items Purpose in Script Why Chosen Over Alternatives
playwright.sync_api sync_playwright Automating browser launching, navigation, DOM element selection, button clicks, and screenshot capturing. Modern browser automation; far faster and more reliable than legacy Selenium, with built-in auto-waiting for DOM elements.
pathlib Path Object-oriented path manipulation for saving screenshot artifacts. Cross-platform path handling for Windows and Linux environments.

3. Detailed Block-by-Block Code Walkthrough

test_browser_interaction.py (Lines 10-30)
with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page(viewport={"width": 1366, "height": 900})
    page.goto("http://127.0.0.1:8501/")
    # Click preset card 5 (Watches)
    page.locator("#preset-btn-5").click()
    assert "REAL_SKU" in page.inner_text("#current-sku-badge")

Explanation: Launches a headless Chromium browser instance matching desktop 1366×900 resolution. Clicks the 5th preset card and asserts that the SKU badge updates to an authentic Flipkart ID (REAL_SKU_...), proving the frontend correctly populates input fields.

# Navigate to Dataset Tab and filter
page.click("#tab-btn-dataset")
page.wait_for_selector("#dataset-table-body button", timeout=5000)
page.click("button[data-cat='Watches & Wearables']")
# Click 'Test Price' on the 3rd row
page.locator("#dataset-table-body button").nth(2).click()
assert "₹" in page.inner_text("#verdict-price")

Explanation: Tests the complete user flow: switches to Tab 2, filters by category, selects a specific product row, clicks "Test Price", verifies that the app navigates back to Tab 1, and asserts that the neural network calculated a valid recommended price (e.g. ₹1,768.75).

4. Important Viva Terms to Highlight

End-to-End (E2E) Testing Testing the complete software workflow from the user interface down to the backend database and neural network, ensuring all integrated components work seamlessly together.
Headless Browser A web browser running without a graphical display. It executes JavaScript, renders CSS, and evaluates DOM trees in memory, allowing lightning-fast automated testing in continuous integration pipelines.
