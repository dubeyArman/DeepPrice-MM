Code Walkthrough: prepare_real_dataset.py

Automated Ingestion, Data Cleaning, Image CDN Fetching, and Stratified Sampling

Data Pipeline Multi-Threading Image Processing

1. File Purpose & Role

This script is the data acquisition and preprocessing pipeline. It transforms 20,000 raw, noisy, unstructured Flipkart e-commerce web crawl records into a clean, multimodal dataset of 1,200 verified products balanced across 6 retail categories, downloading their real photos into standard RGB images.

2. Libraries Used and Technical Justification

Library Imported Items Purpose in Script Why Chosen Over Alternatives
pandas import pandas as pd Loading CSV, filtering nulls, price validation, category grouping, and saving clean master dataset. Standard vectorized tabular library in Python; far faster than manual CSV parsing.
PIL (Pillow) from PIL import Image Opening downloaded images, validating integrity, converting color modes to RGB, and standardizing dimensions. De facto standard Python imaging library; avoids heavyweight OpenCV dependencies for basic image ingestion.
concurrent.futures ThreadPoolExecutor, as_completed Concurrent parallel downloading of 1,200 product images across multiple web threads. Speeds up downloading by ~10x over sequential downloading without complex asyncio setups.
urllib.request import urllib.request Issuing HTTP GET requests with custom User-Agent headers to fetch live image assets from CDN. Native built-in Python library requiring zero external package installations.
re & json import re, json Parsing stringified JSON arrays of image URLs in raw Flipkart dataset columns. Handles both valid JSON arrays and malformed URL strings with regex fallback.

df = df.dropna(subset=['retail_price', 'discounted_price'])
df = df[(df['retail_price'] >= 200) & (df['discounted_price'] >= 150) & (df['retail_price'] <= 100000)]
df = df[df['retail_price'] >= df['discounted_price']] # MSRP >= Discounted Price

Explanation: This block enforces real-world retail logic: it coerces string prices into floating-point numbers, eliminates non-numeric entries, drops rows where MSRP or discounted price is missing, and ensures retail MSRP is strictly greater than or equal to the discounted selling price.

def extract_main_category(cat_str):
    cleaned = cat_str.strip("["'] ")
    parts = [p.strip() for p in cleaned.split(">>")]
    main_cat = parts[0] if len(parts) > 0 else "General"
    if any(k in main_cat for k in ["Mobile", "Tablet", "Electronic"]):

with ThreadPoolExecutor(max_workers=16) as executor:
    futures = [executor.submit(download_image, task) for task in download_tasks]
    for future in as_completed(futures):
        res = future.result()

Explanation: Uses a 16-worker thread pool to download images simultaneously with a 6-second timeout. If a remote CDN link has expired, it falls back to a clean category placeholder image so the pipeline never crashes.

4. Important Viva Terms to Highlight

Stratified Sampling Selecting an equal number of samples (200 SKUs) from each category so the neural network does not become biased toward high-volume categories like clothing or cables.
ThreadPoolExecutor vs ProcessPoolExecutor Threads are ideal for I/O-bound tasks (downloading images from network), while processes are used for CPU-bound tasks (matrix math, training neural networks).

5. Likely Viva Questions & Answers

Q: Why did you filter out items below ₹200 or above ₹1,00,000?
A: Extremely cheap products (e.g., ₹5 screen guards) and extreme luxury goods (₹5,00,000 jewelry) introduce heavy statistical skew in price elasticity. Restricting to ₹200-₹1,00,000 focuses the model on standard consumer e-commerce goods.
