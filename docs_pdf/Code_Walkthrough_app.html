1. File Purpose & Role

This script serves as the backend API server and web application host. Built on modern FastAPI, it serves the interactive frontend dashboard, handles asynchronous multipart file uploads (custom photos), runs real-time pricing inferences, and serves searchable database queries across the 1,200 Flipkart SKUs.

2. Libraries Used and Technical Justification

Library Imported Items Purpose in Script Why Chosen Over Alternatives
fastapi FastAPI, UploadFile, File, Form, HTTPException, Query Building high-performance REST API endpoints with automatic request validation. ~3-5x faster than Flask; built natively on Python type hints and ASGI asynchronous event loops.
fastapi.staticfiles StaticFiles Serving static media (product photos and evaluation plots) directly from the data/ folder. High-efficiency file streaming directly integrated into FastAPI.
fastapi.middleware.cors CORSMiddleware Enabling Cross-Origin Resource Sharing for modern browser clients. Prevents browser CORS security blocks when accessing REST endpoints.
pandas import pandas as pd Querying, filtering, and paginating the 1,200 product records for the dataset explorer tab. Fast in-memory filtering by category and search strings.

Explanation: The primary optimization endpoint. It accepts both standard form fields and multipart image uploads. Uses a singleton pattern (get_optimizer()) to ensure neural network weights are loaded into memory once on startup rather than reloaded on every HTTP request.

4. Important Viva Terms to Highlight

ASGI vs WSGI FastAPI is an Asynchronous Server Gateway Interface (ASGI) framework, allowing it to handle concurrent user requests without blocking, whereas legacy Flask (WSGI) is synchronous.
Singleton Pattern A design pattern that restricts instantiation of a class to a single instance. In app.py, get_optimizer() loads the heavy PyTorch model weights once into memory on server start, preventing memory exhaustion.

5. Likely Viva Questions & Answers

Q: Why did you use FastAPI instead of Flask or Django?
A: FastAPI is significantly faster, natively supports asynchronous file uploads (`UploadFile`), automatically validates request data types with Pydantic, and provides instant OpenAPI documentation.
